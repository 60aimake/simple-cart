**60AI만들기** 채널에서 만든 무료 장보기 도구입니다.
설치도 가입도 광고도 없습니다. 주소만 열면 바로 쓰입니다.

👉 **https://60aimake.github.io/simple-cart/**

## 쓰는 법

1. **계획 중** — 입력칸에 말하거나 적고 「담기」. 아래 분류에서 눌러 골라도 됩니다
   - 키보드의 🎤 를 눌러 말씀하셔도 됩니다. 「양파 대파 우유 두 개」처럼 쭉 말하면 알아서 나눕니다
2. 품목 옆 **숫자칸**이 살 개수입니다. 비워 두면 1 입니다
3. **장보는 중** — 담은 것만 큰 글씨로 보입니다. 산 것은 **체크박스**를 누릅니다
4. **다 샀다** — 빠진 것을 알려 줍니다
5. **카톡으로 보내기** — 목록을 가족에게 보냅니다
