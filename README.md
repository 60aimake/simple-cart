## ★ 집과 마트가 주고받습니다

목록을 **주소 한 줄**로 보냅니다. 받은 사람이 그 주소를 누르면 **거기서 체크하며 장을 봅니다.**

```
집      품목을 고른다
        → [ 카톡으로 보내기 ] → 이름 「김장」 → 목록 + 주소가 카톡으로

마트    주소를 누른다 → 「김장 장보기」 · 「장보는 중」으로 바로 열림
        산 것마다 체크
        계획에 없던 것은 담고 [ 집에 물어보기 ]
        → [ 다 샀다 ] → [ 집에 확인받기 ]

집      김장 장보기 — 확인 부탁드립니다
        산 것 10 / 못 산 것 2 / 더 산 것 1
        아직 마트에 있습니다. 계획과 일치됐으면 「ㅇㅋ」 답장^^

        → 「ㅇㅋ」 면 계산하고 나옵니다
        → 「열무 사와」 면 담고 체크해서 다시 확인받습니다
```

```
서버가 없습니다. 목록은 주소의 # 뒤에 담기고, # 뒤는 서버로 전송되지 않습니다.
24품목 + 이름이 주소 143자입니다. 카톡이 자르지 않습니다.
```

## 쓰는 법

### 1. 계획 중

- 입력칸에 **말하거나 적고** 「담기」. 아래 분류에서 눌러 골라도 됩니다
- 키보드의 🎤 를 눌러 말씀하셔도 됩니다
  「양파 대파 우유 두 개 삼겹살 두 근」처럼 쭉 말하면 알아서 나눕니다
- 품목 옆 **숫자칸**이 살 개수입니다. 비워 두면 1 입니다
- 아래 단추 두 개
  - **카톡으로 보내기** — 이름을 붙여 목록 + 주소를 보냅니다
  - **장보러 갑니다** — 장보는 중으로 넘어갑니다

### 2. 장보는 중

- 담은 것만 큰 글씨로 보입니다. 산 것은 **체크**합니다
- 받은 목록에 없던 것을 담으면 **「계획에 없던 것 — 집에 물어보기」** 가 뜹니다
  누르면 「고등어 도 살까요?」 한 줄이 카톡으로 갑니다
- 아래 단추는 **「다 샀다」 하나뿐입니다**
  - **다 샀다** → 빠진 것을 알려 줍니다
  - 그 창에서 **집에 확인받기** → 산 것 · 못 산 것 · 더 산 것을 글로 보냅니다

### 3. 다시 열면

같은 주소를 다시 누르면 **지난번까지 한 것**을 보여 줍니다.

```
김장 장보기
지난번까지              12 개 중 10 개
남은 것 : 오이 · 고등어
[ 처음부터 ]   [ 이어서 하기 ]
```

**창을 닫아도 누른 것은 남습니다.** 담은 것이 없으면 이 창이 안 뜹니다.
